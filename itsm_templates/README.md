# JIRA DevSecOps Intake Forms

This repository contains standardized JIRA intake forms for enterprise DevSecOps workflows. These templates are designed to ensure comprehensive documentation, security compliance, and operational excellence throughout the development lifecycle.

## Form Categories

1. Feature Development
2. Security Assessment
3. Infrastructure Change
4. Production Deployment
5. Incident Response
6. Compliance Review
7. Performance Enhancement
8. Architecture Review

## Usage Guidelines

- All fields marked with (*) are mandatory
- Link related tickets where applicable
- Attach relevant documentation
- Follow approval workflows as defined
- Update status transitions promptly

## Templates Overview

Each template is designed to capture essential information while maintaining compliance with security and operational requirements. Templates are available in both Markdown and JSON formats for easy integration with JIRA.
